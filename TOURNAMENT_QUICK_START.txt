╔════════════════════════════════════════════════════════════════════════════╗
║                         KEY CONCEPTS                                       ║
╚════════════════════════════════════════════════════════════════════════════╝

SOCKET.IO NAMESPACE: /tournament
ROOMS: tournament:{tournamentId}
EVENTS:
  → subscribe_tournament { tournamentId }
  → unsubscribe_tournament { tournamentId }
  ← tournament_state_updated { registered_count, status, ... }
  ← tournament_player_action { action, botName, userName, ... }
  ← tournament_notification { type, message, ... }

LATENCY:
  Before: 0-10 seconds (until next poll)
  After: <100ms (real-time WebSocket)

ACCESS CONTROL:
  • Live tournament game: Only registered players
  • Finished tournament game: Public (anyone)
  • Non-tournament game: Anyone
  • Admin: Always allowed
